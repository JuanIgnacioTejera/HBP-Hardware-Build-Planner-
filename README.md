# HBP-Hardware-Build-Planner-
**Hardware Build Planner** es una aplicación web moderna y visual diseñada para ayudar a los usuarios a crear, analizar y evaluar configuraciones de PC mediante un sistema de arrastrar y soltar componentes.

La plataforma incluye una amplia base de datos de hardware actual y de generaciones recientes, permitiendo combinar procesadores, tarjetas gráficas, memorias, unidades de almacenamiento, placas madre y fuentes de alimentación para obtener una evaluación automática de la calidad y equilibrio de la configuración.

## Características principales

### Base de datos de hardware completa

Incluye componentes populares y relevantes del mercado:

#### Procesadores

* AMD Ryzen Serie 5000, 7000 y posteriores.
* Intel Core 12ª Generación, 13ª Generación, 14ª Generación y posteriores.

Información mostrada:

* Núcleos.
* Hilos.
* Frecuencia base y boost.
* TDP.

#### Tarjetas gráficas

* NVIDIA GeForce RTX Serie 3000, 4000 y posteriores.
* AMD Radeon RX Serie 6000, 7000 y posteriores.
* Intel Arc Serie B y posteriores.

Información mostrada:

* Núcleos / shaders.
* Memoria VRAM.
* Frecuencias.
* Interfaz PCI Express.

#### Otros componentes

* Memorias RAM DDR4 y DDR5.
* SSD SATA y NVMe.
* Fuentes de alimentación con distintos niveles de potencia y certificaciones (80 Plus White, Bronze, Silver, Gold, Platinum y Titanium).
* Placas madre AM4, AM5, LGA1700 y plataformas legacy relevantes.

## Sistema de construcción visual

Los usuarios pueden:

* Arrastrar y soltar componentes.
* Crear configuraciones completas de PC.
* Comparar distintas combinaciones.
* Analizar compatibilidad básica entre componentes.

## Análisis inteligente de la build

La aplicación genera automáticamente:

### Clasificación de gama

* Entrada.
* Baja.
* Media.
* Alta.
* Entusiasta.

### Balance general

Determina si la configuración presenta cuellos de botella o componentes sobredimensionados.

### Sinergia de componentes

Evalúa qué tan bien trabajan juntos CPU, GPU, memoria y almacenamiento para ofrecer una experiencia equilibrada.

### Resumen de rendimiento esperado

Presenta una evaluación general de la configuración basada en la categoría de los componentes seleccionados.

## Diseño

* Interfaz moderna y minimalista.
* Diseño sobrio enfocado en la experiencia de usuario.
* Navegación rápida e intuitiva.
* Compatible con escritorio y dispositivos móviles.

## Objetivo

Ofrecer una herramienta sencilla, visual y educativa para que entusiastas y usuarios puedan planificar, comparar y evaluar configuraciones de PC sin necesidad de consultar múltiples fuentes externas.
